# بيت شوكوزال للحلويات (مشروع مستقل)

هذا مجلد مشروع مستقل داخل المستودع، مخصص لموقع **بيت شوكوزال للحلويات**.

## المحتوى
- `index.html`: الصفحة الرئيسية باللغة العربية.
- `styles.css`: تنسيق الواجهة.

## طريقة التشغيل محليًا
```bash
cd bayt-shokozal-sweets
python -m http.server 8080
```
ثم افتح:
`http://localhost:8080`

## ملاحظات
- تم تضمين نظام الطلبات والتسليم حسب الأيام التي طلبتها.
- يمكن لاحقًا ربط النموذج بخدمة استقبال طلبات (مثل Formspree أو API مخصص).
